This page is a static GitHub Pages landing page for the project preview. The full marketplace application uses Java, Servlets, JSP, and Tomcat, so dynamic features cannot run directly on GitHub Pages.

View source repo Open project README
Static preview only: This GitHub Pages site is intentionally limited to static content. Login, cart, checkout, database-backed actions, admin dashboards, and seller flows require the Java/Tomcat backend.

Included in static preview

  • Project landing page
  • Marketing and overview content
  • Repository links

Requires backend

  • User registration and login
  • Seller dashboard
  • Cart and checkout
  • Order management
  • Database-backed product actions

Deployment note

  • GitHub Pages hosts static HTML
  • Java Servlet/JSP app requires Tomcat
  • Use Azure App Service or similar host for the live app
